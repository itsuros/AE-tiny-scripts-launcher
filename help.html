AE Tiny Scripts Launcher ヘルプ

1. 概要とバージョン表示

Adobe After Effects 向けの Script（.jsx / .jsxbin）、Expression、Animation Preset（.ffx）を一元管理・実行できる CEP パネルです。

  • DEV（開発版）: DEV v0.0.0 (rev.N) のようにコミットごとのリビジョンを表示します。
  • PROD（本番版）: v0.0.0 のようにリビジョンを省いた正式表記で表示します。
  • パネルの横幅を狭くした場合は、バージョン表示がコンパクトなアイコンに自動で切り替わります（マウスオーバーで詳細を確認できます）。
  • Script / Expression / FFX の個別バージョン: 各スクリプトやプリセット自身のバージョンは Launcher 本体とは別に管理され、各カード・リスト行・外部適用先ウィンドウに表示されます（ヘッダコメント @version / サイドカー .meta.json / GitHub の launcher-manifest.json / 手動入力に対応）。

2. 表示切替・カードサイズ・検索・並び替え

  • アイコン型 / リスト型切替: ツールバー右上の切替ボタンで表示形式を切り替えられます。
  • カードサイズ変更・リセット: Size スライダー（55%〜140%）でアイコンカード全体のサイズを調整し、一度に多くのツールを表示できます。右側の ↺ ボタンで 100% にリセットできます。
  • 検索: ツールバーの検索欄に入力すると、名前・種別・タグ・説明で即座にインクリメンタル検索できます（Esc キーでクリア）。
  • 並び替え: Custom Order 選択時はドラッグ＆ドロップ、または ⇅ Reorder モードの上下ボタンで表示順を変更できます。

3. Script・Expression・FFX の実行と適用先選択

  • Script（JSX / JSXBIN）: クリックすると即座に After Effects 上で実行されます。
  • Expression / FFX: クリックすると CEP パネル外に独立したフローティングウィンドウが開き、適用先や詳細オプションを指定して適用できます。
  • Expression 適用オプション: 選択中プロパティ / 共通プリセット / レイヤープロパティツリー検索から選択でき、置換・追記・先頭挿入やキーフレーム処理（保持 / 現在値フリーズ削除 / 全削除）を指定できます。
  • FFX 適用オプション: AE 選択レイヤー / チェック選択 / 新規調整レイヤー / 新規平面 / 新規ヌルへの適用や、時間基準（現在時刻 / インポイント / 0:00）、既存エフェクト削除を指定できます。

4. ローカル AE-tiny-scripts・複数ローカルフォルダ・GitHub 同期・同名アイコン

  • ローカル AE-tiny-scripts 読み込み（専用オプション）: Settings の「Local AE-tiny-scripts Repository」を有効にしてローカルのレポジトリパスを指定すると（Auto で自動検出も可）、launcher-manifest.json や同名アイコン・個別バージョンを含めて専用ソース（TINY）として読み込みます。
  • ローカルフォルダ読み込み: Settings の「Local Script Folders」に複数のフォルダを登録すると、配下のファイルを再帰スキャンして自動登録します（ツールバーのフォルダボタンからいつでも再スキャン可能）。
  • GitHub レポジトリ同期: Settings の「GitHub Scripts Repository Sync」に owner/repo 等を設定すると、対象ファイルを自動ダウンロードします。
  • 同名画像の既定アイコン化: スクリプトと同じディレクトリに同名の画像（.png, .svg, .jpg 等）が配置されている場合、自動的に既定アイコンとして表示されます。

5. 本体自動アップデート

Settings の「Launcher Self-Update」でリリース元 GitHub レポジトリを設定すると、GitHub Releases API から新しいバージョンを確認し、ワンクリックでダウンロード・更新できます。
